# arigoldring.github.io

Personal portfolio for Ariel Goldring, live at **[arielgoldring.dev](https://arielgoldring.dev)**.

Plain HTML, CSS, and a small amount of JavaScript (mobile menu, copy-email buttons). No build step: GitHub Pages serves the repo root as-is, with the custom domain set in `CNAME`.

To preview locally, open `index.html` in a browser or run `npx serve .` from the repo root.
